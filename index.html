Sportsbook odds import

Select a sportsbook, then paste Gemini's four-column TSV (Player Name, Line, Over Odds, Under Odds). A new import replaces only that book's current-round board; unmatched names and invalid rows are reported. Other books and rounds remain intact.

The Best screen chooses the highest-ROI Over and Under separately for each player. Different lines are priced independently. Odds are manual snapshots, not live feeds; the last import time for each sportsbook appears above.

Model: strokes = par + your field prediction − (player fantasy points − uploaded field fantasy average) / 4.1 (or edited divisor). Fair odds use a normal approximation. Missing or invalid standard deviations use the tournament default (initially 3.00). These are full-round, pre-round model probabilities; they do not account for holes already completed.
