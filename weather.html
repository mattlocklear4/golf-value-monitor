Import another tournament / retrieve via API

This prototype starts with Bermuda data offline. Retrieved tournaments are added to the course selector. You can also import Visual Crossing Timeline CSV files (one file per year) to explore a new course. API retrieval is a prototype option; for production, the API key should be stored behind a server-side endpoint rather than in a public HTML page.
