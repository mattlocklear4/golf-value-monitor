1. Projections

Paste player, projected full-round strokes, round standard deviation. One player per line. Example: Doug Ghim,67.3,2.96. This temporary input is intentionally separate from the live board.

2. Kalshi public market data

Enter the exact series ticker for Kalshi's golfer round-score markets, then load open markets. This prevents accidentally matching unrelated golf markets. Public API requests may be blocked by browser CORS; if so paste the API's JSON response below.

3. Explicit market mapping and valuation

Fee estimate is an input, not an official Kalshi fee calculation. For research, enter your expected fee per contract; ROI subtracts that cost. A value of zero shows gross ROI.

Kalshi contract wording varies. To avoid incorrect bets, markets are not automatically interpreted as over/under. For each ticker, set the player, strike, and whether YES means the player's score is OVER or UNDER that strike. Only mapped contracts with half-stroke thresholds are valued. Confirm the market's exact event, round and settlement wording before selecting a player. Use YES ask to buy YES and NO ask to buy NO; indicative prices, excluding fees and slippage.
